プライバシーポリシー

窓カレンダー（以下「本アプリ」）は、オーナーが自分の Google カレンダーの予定を、自分が招待した人に閲覧専用で見せるためのアプリです。本アプリでの情報の扱いを次のとおり定めます。

1. 利用者

  • 運営者：本アプリを運営する人です。オーナーとして使える人を決めます。
  • オーナー：運営者が許可した Google アカウントでログインし、自分のカレンダーを共有する人です。
  • 閲覧者：オーナーから招待された人です。Google アカウントは使いません。

2. 取得する情報

  • オーナーの Google アカウントのメールアドレス（ログインできる人を確かめるため）
  • オーナーの Google カレンダーにある、カレンダーの名前と色、ラベル、予定のタイトル・日時・ラベル
  • オーナーが設定した表示名と、閲覧者ごとの表示の設定

予定の説明欄・場所・参加者・会議のリンク・添付ファイルは取得しません。Google カレンダーへのアクセスは読み取り専用で、予定を作成・変更・削除することはありません。

3. 利用目的

取得した情報は、オーナーが招待した閲覧者に、オーナーが許可した範囲で予定を表示するためだけに使います。閲覧者ごとに、見せる予定と項目（タイトル、カテゴリ、「予定あり」のみ、など）をオーナーが設定します。

4. オーナーどうしの分離

情報はオーナーごとに分けて保存します。オーナーは、自分の予定・閲覧者・設定だけを扱えます。ほかのオーナーの情報を見たり変えたりすることはできません。閲覧者に、オーナーのメールアドレスを見せることはありません。

5. 保存と管理

  • 情報は Cloudflare のサービス（Workers、D1）に保存します。
  • Google から取得した予定は、表示を速くするため短い時間（数分）だけ保存し、その後は取得し直します。
  • Google へのアクセスに使う認証情報（トークン）と閲覧者の ID は、暗号化して保存します。
  • オーナーが削除された場合は、そのオーナーの情報をすべて消します。

6. 運営者による情報へのアクセス

運営者は、本アプリの管理画面では、ほかのオーナーのメールアドレス・表示名・最終ログイン日時だけを見られます。ほかのオーナーの予定や閲覧者は、管理画面には表示されません。

ただし、情報の保存先は運営者が管理しているため、運営者は仕組みの上では、保存先を直接開いてオーナーの情報（保存中の予定のタイトルなど）を読むことができます。運営者は、障害への対応など必要な場合を除き、オーナーの情報を見ません。

7. 第三者への提供

取得した情報を販売したり、上の目的以外で第三者に提供したりすることはありません。

8. Google API Services User Data Policy の遵守

本アプリによる Google API から取得した情報の利用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

9. 閲覧者の情報

閲覧者については、オーナーが付けた表示名と、最後に閲覧した日時だけを記録します。閲覧者の端末には、参加状態と、最後に表示したカレンダーを覚えておくための Cookie を保存します。

10. お問い合わせ

本アプリについてのお問い合わせは、お問い合わせフォームからお送りください。
