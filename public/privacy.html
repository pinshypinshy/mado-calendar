プライバシーポリシー

窓カレンダー（以下「本アプリ」）は、運営者が自分の Google カレンダーの予定を、運営者が招待した人に閲覧専用で見せるためのアプリです。本アプリでの情報の扱いを次のとおり定めます。

1. 取得する情報

  • 運営者の Google アカウントのメールアドレス（管理画面にログインできる人を確かめるため）
  • 運営者の Google カレンダーにある、カレンダーの名前と色、ラベル、予定のタイトル・日時・ラベル

予定の説明欄・場所・参加者・会議のリンク・添付ファイルは取得しません。Google カレンダーへのアクセスは読み取り専用で、予定を作成・変更・削除することはありません。

2. 利用目的

取得した情報は、運営者が招待した閲覧者に、運営者が許可した範囲で予定を表示するためだけに使います。閲覧者ごとに、見せる予定と項目（タイトル、カテゴリ、「予定あり」のみ、など）を運営者が設定します。

3. 保存と管理

  • 情報は Cloudflare のサービス（Workers、D1）に保存します。
  • Google から取得した予定は、表示を速くするため短い時間（数分）だけ保存し、その後は取得し直します。
  • Google へのアクセスに使う認証情報（トークン）と閲覧者の ID は、暗号化して保存します。

4. 第三者への提供

取得した情報を販売したり、上の目的以外で第三者に提供したりすることはありません。

5. Google API Services User Data Policy の遵守

本アプリによる Google API から取得した情報の利用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

6. 閲覧者の情報

閲覧者については、運営者が付けた表示名と、最後に閲覧した日時だけを記録します。閲覧者の端末には、参加状態を保つための Cookie を保存します。

7. お問い合わせ

本アプリについてのお問い合わせは、お問い合わせフォームからお送りください。
